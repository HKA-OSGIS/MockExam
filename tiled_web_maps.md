# Tiled Web Maps

## Question

What is a tiled web map?

## Answer

In a tiled web map, the world is divided into small squares (tiles)
on zoom levels 0 to about 18. The browser loads only the tiles
it needs.

Tiled web maps use the EPSG:3857 (Spherical Mercator) projection.
Raster tiles are usually PNG images with 256 x 256 pixels.
