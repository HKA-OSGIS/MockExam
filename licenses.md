# Open Source Licenses

## Question

Name two frequently used Open Source Software licenses and 
explain what their difference is.

## Answer

The "MIT" license is a license without share-alike and allows
anyone to build software on top of MIT licensed work.

The "GNU GPL" license is a share-alike license that requires
work built on top of GPL licensed content to also be GIT licensed.

Both licenses require attribution (i.e. naming the software 
that was used in the building process).
